# P09 配置库 V2 页面接入

日期：2026-11-25。分支：`codex/p09-management-pages`。

## 已实现

- 配置库采用独立工作区导航：版本与规则、状态语义、人员与通知。保留主导航、功能验收入口和当前身份。
- 版本与规则拆为版本范围、规则设置、工作日历；状态语义拆为状态映射、影响与恢复；人员与通知拆为人员与权限、通知对象。工作区与页签保存到 URL，刷新可恢复。
- 版本范围接入真实版本清单、负责人、同步起点、本系统状态、同步状态、自动同步和来源绑定。纳入窗口只使用已批准候选版本及已确认负责人，两者均须明确选择；纳入、同步仍使用原有鉴权与 CSRF 接口。失败保留已有事实，不自动重试未知提交结果。
- 规则设置显示系统、版本和需求层级、生效来源、继承摘要、进度判断和采集/关注配置。通过编辑窗口修改，保留现有服务端预览、确认保存、原因、版本校验、逐项继承和职能互斥。取消窗口不会保存，重新打开使用已保存生效值。
- 工作日历增加月视图和日期编辑入口；使用实际保存的日期类型和工作时段，不推测节假日名称。保存仍复用既有日历预览及确认接口。
- 状态语义展示已保存映射与恢复状态；编辑在独立窗口中完成，关闭编辑窗口清除未保存映射草稿。恢复验证继续使用现有接口，不把保存成功当作恢复成功。
- 人员与权限展示当前身份或所有者可读的权限清单，并将已有身份登记、权限修改、人员启停和映射启停迁入独立编辑窗口；自改权限后重新登录、服务端最后所有者保护、原因及会话撤销逻辑不变。通知对象只读展示已确认接收规则，不推算具体接收人数或发送消息。
- 首次计划基线、不适用确认保留在规则设置中；功能验收入口继续保留。

## 复用与视觉依据

- 样式来自 4210 实际加载的 V2 `config.css`、`version-rules.css`、`rules-editor.css` 等资源。保留本地 Plus Jakarta Sans 400/500/600/700 和浅色主题。
- 版本工作区的后续覆盖值为标题 22px、页签 13px、桌面页签间距 28px、内容顶部 20px；不能仅按较早的 config.css 值实现。
- 不修改原型、不新增依赖、不变更业务数据计算与权限。
