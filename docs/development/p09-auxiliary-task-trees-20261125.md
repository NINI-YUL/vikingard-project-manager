# P09：辅助任务树结构识别

日期：2026-11-25。用户确认辅助任务可以拆分给多人执行；父任务与子任务都默认视为可执行工作。

## 规则

- 需求下的普通任务仍识别为辅助子单。
- 辅助子单下的普通任务递归识别为辅助子单。
- 验收总单下的普通任务树继续识别为验收任务单。
- 优化需求下的普通任务继续识别为优化任务单。
- 辅助任务树参与测试阶段完成判定；未映射或未终态时测试阶段保持未完成。
- 专业阶段结构异常仅检查专业子单、职能配置和需求自身；辅助任务树未知不再使基础流程或全部内容不可计算。
- 找不到父级或父级循环仍识别为 unknown，并使测试阶段不可计算。
