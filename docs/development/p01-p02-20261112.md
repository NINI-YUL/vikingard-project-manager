## 2. 最小实现及文件责任

一个 Node.js 应用、一个 PostgreSQL 业务库，不引入框架、容器、消息队列或额外 Node.js 安装。唯一运行依赖为锁定版本的 pg。

| 文件 | 责任 |
| --- | --- |
| `package.json`、`package-lock.json`、`.gitignore` | 可重现依赖、命令及本地文件排除 |
| `app/config.mjs`、`app/config.example.json` | 外部配置、固定安全错误、内网 HTTPS 条件；示例不含真实凭证 |
| `app/database.mjs`、`migrations/001-identity-access.sql` | 带校验和及事务锁的前向迁移（SQL 保留原始字节，跨工作区校验稳定）；人员、身份、授权、会话、OAuth 请求及审计 |
| `app/security.mjs` | 四档权限、一次性核对名单初始化、逐次授权、撤权和最后所有者事务保护 |
| `app/dingtalk.mjs` | OAuth state 与浏览器绑定、一次性消费、用户身份及企业成员核验；不存令牌 |
| `app/server.mjs`、`app/main.mjs` | HTTP/HTTPS、服务端路由、Origin/CSRF、固定错误、启动失败不降级放行 |
| `app/public/` | 登录与权限人工验收入口，不含模拟登录开关 |
| `scripts/application.mjs`、`scripts/Run-Local.ps1` | 独立业务库准备、迁移、初始化与本机启停 |
| `scripts/prepare-test-database.mjs`、`tests/` | 仅接受专用测试库的数据库、HTTP 和安全回归 |

权限在服务端落实：无权限不能访问业务接口；查看者不能写；管理员不能授予权限；只有所有者能管理授权。权限变更、人员停用及身份映射解除会撤销该人员全部旧会话；恢复身份不恢复旧会话。初始化不是“首个登录者自动成为所有者”。

所有授权及身份变更先锁数据库中的唯一安全状态行，再重查操作者、更新目标、检查有效所有者数、撤销会话并写审计。任何步骤失败整体回滚。最后一名所有者不能被降级、撤权、停用或解除映射；并发情况同样受保护。没有提供直接删除人员、删除身份、清空权限或改写身份 ID 的 HTTP 路径。

## 4. 开发侧可重复运行

在独立开发工作区使用 PowerShell。以下命令只引用文件路径，不把凭证放入参数。

```powershell
& 'C:\Program Files\nodejs\npm.cmd' ci --ignore-scripts --no-fund --no-audit
.\scripts\Run-Local.ps1 -Action StartDatabase
& 'C:\Program Files\nodejs\node.exe' scripts/application.mjs provision
$env:VIKINGPM_TEST_CONFIG = 'F:\VikingPM\security\integration-test.json'
& 'C:\Program Files\nodejs\npm.cmd' test
.\scripts\Run-Local.ps1 -Action Start
.\scripts\Run-Local.ps1 -Action Status
```

初次隔离测试前由开发侧执行 `node scripts/prepare-test-database.mjs`。普通 `npm test` 未配置 VIKINGPM_TEST_CONFIG 时会明确跳过真实数据库测试；不能把这种结果报告为完整验收通过。

后续只迁移使用 `npm run migrate`。迁移文件一经应用不得改写，追加下一份 SQL；历史不匹配时停止，不清空数据库。没有自动降级或重置数据库命令。

停止顺序：先 `.\scripts\Run-Local.ps1 -Action Stop`，再 `StopDatabase`。当前 Stop 终止已核对 PID 和启动时间的应用进程；处理中请求可能中止，数据库事务回滚。P04/P07 的业务补读和通知恢复尚未开发，不能据此声称已有业务恢复能力。StartDatabase 使用隐藏独立进程及有界等待，避免 PowerShell `Start-Process -Wait` 等待 PostgreSQL 后台子进程树。

后台进程输出位于 `F:\VikingPM\logs\application.out.log` 与 `application.err.log`，只记录固定状态，不记录请求 URL、Cookie 或配置。用户遇到错误先反馈页面提示，不复制完整日志或浏览器地址中的授权参数。
