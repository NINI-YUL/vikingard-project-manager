# P09 核心需求工单时间线：实际执行时间

日期：2026-11-27（北京时间）。本次只交付核心需求详情中的实际时间展示，不代表 P09 全部完成。

## 实现范围

- 工单左侧改为任务名称、预估起止与计划工作日、实际起止与执行状态三行。
- 实际线使用 V2 的 4px 高度、3px 圆角、状态配色和独立轨道；预估条仍使用原计划日期定位。
- 共享日期轴覆盖计划及有效实际范围，允许实际早于预估、晚于预估以及无预估但已有实际记录。
- 核心专业子单读取 timing.development，测试工作单读取 timing.test。复用来源状态动态生成的轮次，不改接口、数据库、状态映射或计时算法。
- 多轮采用第一轮开始到最后一轮结束的单条包络线。最后一轮尚未结束时延长到北京时间今天，包含当天，不把今天写入真实结束字段。包络线包含暂停间隔，左侧工作日继续采用后端排除暂停后的累计结果。
- 只有存在有效实际结束且当前状态为终态时显示圆点。已进入终态但结束时间缺失时不显示圆点，不补造结束时间。
- 无实际开始记录不绘线；明确未开始显示“实：未开始”，未知或异常记录显示“实：实际时间不可判断”。未来实际开始不绘线，也不扩大日期轴。
- 时间线整行点击、Enter、空格打开复用现有任务详情面板的抽屉；关闭及 Esc 后恢复行焦点，保留来源历史读取和移动端横向滚动。
