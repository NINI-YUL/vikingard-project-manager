# P09 人工确认实际时间后直接计算工作日

日期：2026-11-27（北京时间）。分支：codex/p09-management-pages。

## 用户确认的口径

人工修改并确认保存，就是对该轮实际起止的核实。不能仅因人工时间不同于 TB，继续要求用户重复核实。

- 已保存的历史人工修正同样适用，无需再次填写或保存。
- 按生效的起止和公司工作日历重算历时，扣除该来源轮次已知的暂停及其他不计时区间；人工确认区间中没有来源记录的部分按公司工作时段计算。
- 新的分钟时间按精确时刻计算。旧日期修正按日期粒度计算，包含起止当天的公司工作时段；仍与来源同日的旧字段继续保留原来源精确时间。不向旧记录写入虚构的时分。
- 缺少开始时间时仍无法计算。没有结束时间时累计到当前时刻，未来开始尚未发生时为 0 且不绘制实际线。已填写的未来起止仍允许保存。
- 多轮先累计未取整小时数，再统一按 7.5 小时／日向上取整到 0.1 工作日。
- 后续 TB 来源变化仍提示字段冲突。轮次拆分、合并及关联不确定时仍要求重新关联；起止倒置继续保留上次有效值。人工确认不取消这些同步保护。
- 保留原始 TB 事实、预估条、状态逻辑、鉴权、原因审计和批量原子提交。无需数据库迁移，也无需新的“核实通过”按钮。
