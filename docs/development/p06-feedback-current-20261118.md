## 依据与规则

依据 `CONTEXT.md`、[首版启动记录](../product/first-release-development-startup.md)、[首版开发计划 P06 / 4.1](../product/first-release-data-access-and-development-plan-20261112.md)、[操作手册](../product/operator-manual-and-entry-standards.md)、[只读样本验证](../research/dingtalk-feedback-readonly-validation-20261109.md)、[P04](p04-persistent-sync-20261116.md) 与 [P05](p05-rules-stages-20261117.md)。

复用 `scripts/dingtalk-feedback-readonly-check.mjs` 的编号、标题、平台创建人和提交人、整数进度及风险说明校验。正式处理不使用其 `latestCheckedCandidate` 作为有效依据；必须从已确认来源重新读取平台原记录，再重新读取当前 TB 事实，最后在本机校验和入库。

- 来源由管理员明确核对现有 baseId / sheetId 并确认。该操作只登记本机来源，不新建表格、不写外部记录。首次确认时间保留为审计，不额外作为反馈提交时间门槛。
- 执行者用项目内 TB 稳定用户 ID 与本系统已确认的钉钉人员映射。后台角色与反馈资格独立；无后台权限但身份已确认、启用的实际执行者可以反馈。不能按姓名或管理员身份代填。
- 原始编号先唯一关联当前受控项目中的稳定工单，保存绑定；修订不能凭改写编号把已有记录改绑其他任务。再次核对当前 TB 内部任务 ID、项目、唯一编号前缀和编号、标题、实际执行者及可信平台创建人。前缀缺失不猜测。
- 只接受活跃版本、当前打开跟踪区间内的核心专业子单。职能必须已确认；任务、父需求结构和来源必须可核对；状态语义已确认并通过恢复验证，来源明确未完成且未归档。终态、移出范围、读取失败或身份停用后重新校验。
- 平台创建时间必须可信且不晚于读取时间。原记录第一次读到的创建时间和创建人固定；之后修改这些平台事实会拒绝。按平台创建时间排序，编辑时间和本系统观察时间不改变提交顺序。
- 同任务选择最新通过当前资格校验的提交。错误编号、标题、非执行者、非整数或超出 0–100 的进度不进入有效历史。旧通知链接不按轮次失效；提交仍须处于当前跟踪区间。100% 不修改 TB 完成状态或阶段结果。
- 风险或阻塞必须填写原因与所需协助，并沿用旧校验器的人工复核要求。管理员可对当前校验上下文的风险说明确认；复核留依据与审计。被拒绝记录和含义未确认的“已暂停”不能借此放行。资格或内容变化后原复核不能绕过新校验。
- 同刻且业务内容相同的候选稳定选择；同刻且内容冲突时，按本次用户明确要求保留上次仍有效的确定值并标记待复核。上次确定值已失效则显示未知。不得靠抓取顺序决定进度；后续提交时间更晚的正确反馈可以解除冲突。

## 持久化与事务

前向迁移 `008-feedback-current.sql` 新增来源、执行者映射、原始记录、原始修订、校验、有效历史、当前值和风险复核表，并扩展来源编号前缀。001–007 未改写。

原始记录按来源及平台记录 ID 唯一。原始修订按稳定内容摘要去重；A→B→A 读取恢复原修订指针，保留 A/B 原始内容。校验按原始修订及当前资格上下文去重，并记录当前校验指针。有效历史对原始修订唯一，重复读取或重新校验不会重复生效；历史曾有效不代表当前仍有效。

同一来源的采集事务互斥。外部读取不持有人员安全锁；采集前后重新核对当前管理员权限。权限、身份、来源与状态写入共用既有安全锁，反馈处理再取得反馈锁。原始记录、修订、校验、有效历史、当前值和读取审计在同一事务提交；失败全部回滚。TB 来源同步使用已有独立事务，失败会保留上次来源事实、记录失败并撤去无法确认的当前反馈资格。

成功的完整表读取若发现原始记录缺失，保留已有证据并暂停其参与当前值。分页失败不当作完整读取，不据此标记记录缺失。沿用只读读取器的完整分页检查；单次最多 10,000 条且总 JSON 不超过 8 MiB，超限整轮拒绝，不静默截断。

同步成功或失败、人员身份变更、规则及状态映射保存/恢复验证、反馈来源及执行者映射保存后，都在事务中重新校验。查询入口也重新校验；查看者只读取派生结果，不能确认来源、改映射、采集或复核。未知进度用 null 表示，不填 0。

业务数据库账号对原始修订、校验、有效历史、人工复核表仅有 SELECT / INSERT，无 UPDATE / DELETE。本机已核对原始修订不能修改、有效历史不能删除。
