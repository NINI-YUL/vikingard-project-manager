## 后续每次操作的要求

1. 调用凭证读取函数前，先读取函数签名及调用示例，确认参数是路径还是内容。只传本机配置文件路径，不把文件内容拼入命令。
2. 不在聊天、截图、工具输出、命令参数、日志、测试快照、文档或提交中展示密钥、Token、授权码和完整凭证文件。验证时只输出明确允许的成功状态或必要业务结果。
3. 鉴权和凭证读取失败时，只输出固定失败信息或经过筛选的状态码；不要输出完整异常、接口响应、请求头或带敏感参数的地址。
4. 测试只用虚构凭证。相关读取及异常处理修改必须验证正常读取仍可用，错误信息和堆栈都不含传入内容。
5. 再次发生泄露时，立即停止相关操作，告知用户暴露范围并更换凭证；不复述泄露值。更换后只做最小鉴权验证，不默认旧令牌随之撤销。

这些要求降低重复风险，不代表已完成整个项目的安全审计。
