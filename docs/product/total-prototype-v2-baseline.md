## 后续每次调优的固定流程

1. 阅读本基线及目标功能的业务决策，复制总原型 v2 到新的独立预览目录。
2. 只在独立预览中调整目标页面，继承 D 版的共享样式。原型 v2 在评审期间保持不变。
3. 提供效果图和可操作预览，说明字段、入口、结构和业务规则是否变化，以及已验证内容。
4. 用户明确确认效果后，再把确认范围内的改动同步到总原型 v2；一般讨论、提出问题或要求继续调整不等于确认。
5. 同步时保留总原型 v2 已有的其他修改，不能用较旧的预览整份覆盖。验证内容完整性、关键入口、筛选和响应式；按需检查共享组件对其他页面的影响。
6. 更新下面的同步记录，说明来源、用户确认内容、修改范围与验证结果。
7. 保存或同步文件不等于 Git 提交、推送或发布；这些动作按用户当次授权执行。
