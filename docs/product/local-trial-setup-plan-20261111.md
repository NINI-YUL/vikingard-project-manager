## 3. 免费优先的内网访问建议

用户已决定首阶段只做内网访问。现阶段不购买域名、服务器或外网隧道；同一公司网络或公司 VPN 内的用户直接访问本机服务。

公网临时入口暂缓。后续若必须外网访问，再评估免费临时网址；它不作为首阶段依赖。

实施条件：

- 先完成真实后台的登录及四档权限；当前总原型不能直接作为正式后台公开。
- 只允许指定测试人员访问，不使用裸露的匿名隧道。邮箱验证不能替代后台业务权限。
- 先用测试数据验证内网指定人员可访问、未授权人员被拒绝，以及钉钉登录回调可用。
- 浏览器访问入口和 Teambition Webhook 回调分开处理。内网地址能否被 Teambition 服务端访问，需单独验证；回调仍要独立验签、校验租户及项目。
- 暂无稳定入口时，优先在本机验证业务流程及定时读取/对账；不能将历史 Webhook 验证成功写成已部署长期回调。
- 本机关闭、休眠或断网会中止本机处理。外网隧道不能替代运行设备。

后续若必须外网访问，再单独比较免费临时入口或稳定托管方案；不擅自购买域名或服务。不默认公司业务可以使用 Tailscale Personal 免费计划。

### 重启与最终状态

数据库重启后，通过独立连接读取恢复库中的测试记录，值仍为 environment-ok，持久化检查通过。随后 pg_ctl 停止命令成功，最终数据库停止，没有设置开机启动。

验证命令曾直接捕获 pg_ctl start 的输出，后台进程继承输出句柄导致命令等待。改用独立连接核验后另行停止数据库；原等待命令随后重复停止，报告“Final stop not confirmed”，属于重复停止结果，不覆盖独立停止已成功的事实。后续启停工具需避免捕获启动进程继承的输出管道，不能把该验证命令直接当作一键启动脚本。
